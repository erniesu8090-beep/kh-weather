# 高雄小港 / 林園 氣象即時監控系統 🌧️🛰️

專為高雄小港、林園地區設計的即時氣象與降雨監控儀表板。支援中央氣象署（CWA）高解析度雷達回波、全臺衛星雲圖動態播放以及小港重點測站雨量監控。

🌐 **線上即時網址**：[https://erniesu8090-beep.github.io/kh-weather/](https://erniesu8090-beep.github.io/kh-weather/)

---

## ✨ 核心功能特色

- 🎯 **林園降雨雷達 (250m 超高解析度)**
  - 專屬林園降雨雷達觀測，每 2 分鐘更新一筆，精準捕捉小港、林園區域降雨動態。
- 🌀 **全臺雷達觀測 (無地形 / 有地形)**
  - 串接全臺雷達回波圖，支援 **動態循環播放**、**逐格檢視** 與 **滑桿拖曳控制**。
- 🛰️ **全臺衛星雲圖**
  - 臺灣彩色色調強化衛星雲圖，支援多影格時序動畫與時段切換（0.5h / 1h / 2h / 3h）。
- 🌧️ **全高雄即時雨量觀測站自訂切換（最多選 2 站）**
  - **預設站點**：**鳳森測站 (C0V45 · 小港)** & **鳳鼻頭測站 (C0V84 · 小港)**。
  - **支援切換**：可隨時點擊卡片標題下拉切換至高雄市區（鳳山/前鎮/苓雅/三民/鼓山/左營/楠梓/旗津）、林園、大寮、大樹、仁武、北高雄（岡山/路竹等）及東高雄山區等 90+ 個觀測測站。
  - **自動記憶**：選擇的測站會自動儲存於瀏覽器（`localStorage`），下次打開自動保留偏好。
  - 即時顯示 10 分鐘、1 小時、3 小時、24 小時與本日累積雨量，並依雨勢自動標註「降雨中 / 大雨 / 豪大雨」。
- 📱 **PWA 漸進式 Web App 支援**
  - 內建專屬深藍雷達雲雨圖示與 Service Worker，可直接安裝為手機或電腦原生桌面應用程式（無網址列）。
- ⚡ **雙模式架構**
  - **純前端直連 (GitHub Pages)**：透過 CWA OpenData API 與動態 JSONP 直連，免伺服器也能完全運作。
  - **本機伺服器 (`server.py`)**：純 Python 標準函式庫實現，支援本機資料快取與獨立桌面視窗啟動。

## 📱 手機端安裝方式 (iOS / Android)

1. 用手機瀏覽器打開 [https://erniesu8090-beep.github.io/kh-weather/](https://erniesu8090-beep.github.io/kh-weather/)
2. **Android (Chrome)**：點擊右上角 `...` 選單 → 點擊 **「安裝應用程式」**（或 **「加到主畫面」**）。
3. **iPhone (Safari)**：點擊底部「分享」圖示 → 點擊 **「加入主畫面」**。
4. 手機桌面即會產生專屬的氣象監控 App 圖示，點開後全螢幕瀏覽！

---

## 💻 電腦端使用方式

### 方式 A：網頁版安裝為應用程式 (推薦 ⭐)
1. 用 Chrome 或 Edge 開啟網址。
2. 點擊網址列右側的 **「安裝應用程式」** 按鈕（或選單中的「將此網站安裝為應用程式」）。
3. 桌面即會建立專屬捷徑，點開後為獨立小視窗。

### 方式 B：本機 Python 伺服器啟動
1. 雙擊執行 `啟動林園氣象監控.bat`。
2. 系統會自動啟動本地 Web 伺服器並開啟專屬視窗。

## 🛠️ 專案檔案結構

```text
├── index.html            # 前端主要儀表板介面 (HTML / CSS / JavaScript)
├── manifest.json         # PWA 應用程式設定檔
├── sw.js                 # PWA Service Worker (支援離線快取與安裝)
├── server.py             # 本地 Python 代理與 Web 伺服器
├── 啟動林園氣象監控.bat    # Windows 一鍵啟動腳本
├── icon-192.png          # PWA 192x192 應用程式圖示
├── icon-512.png          # PWA 512x512 高畫質應用程式圖示
├── apple-touch-icon.png  # iOS Apple Touch 圖示
├── favicon.ico           # 網站與桌面捷徑圖示
└── README.md             # 專案說明文件
```
